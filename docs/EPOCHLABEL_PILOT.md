# EpochLabel 小规模采集协议

状态：准备阶段，尚无人工采集材料，目前无法安排评分者。目标是核对标签含义和信号状态对应，现有研究基线保持不变。

## 首轮安排

邀请 2–3 位熟悉 EEG 的评分者独立检查同一批约 40–60 个 epochs。选择少量有权用于研究的数据，先保留一组按原顺序或随机抽取的自然样本，再补充明显伪迹与难判断样本；分别记录自然抽样和补充抽样，避免把人为平衡比例当成实际伪迹率。初轮规模用于发现采集问题，不足以证明泛化能力。

项目先分配 lab、study、participant、recording 的匿名 ID，并单独保存本地来源映射。同一被试的所有文件、处理状态及重复片段沿用同一 participant。评分者使用本机稳定匿名 rater ID；换电脑时由项目登记对应关系。数据不随代码或发行包发布。

## 评分前固定

1. 固定待判断的输入及已采用处理状态、通道范围、显示滤波、时间范围和尺度。需要比较处理前后时分别保存会话，在同一 epoch 身份下记录各自状态。
2. 每位评分者使用独立目录中的数据副本，从没有 .eegqc.json 的未标注输入开始，防止自动恢复其他人的记录；同一来源的项目分组与 epoch 编号保持一致。首轮关闭阈值、ICLabel 或 EpochLabel 建议，减少建议暴露差异。
3. 每人先独立完成一份真实文件的打开、标记、保存、关闭恢复和导出流程，记录阻塞位置、实际行为和预期行为。

## 标签规则

| 观察与决定 | 当前应用记录方式 | 研究用途 |
|---|---|---|
| 已检查、可接受 | 确认保留，使用信号质量原因 | acceptable |
| 已检查、有伪迹 | 标记为坏并填写实际原因 | artifact；仅有明确证据时记录伪迹类型 |
| 难判断 | 原因选择 uncertain，备注疑点 | uncertain；不强行并入好/坏训练目标 |
| 行为或条件排除 | 使用 behavioral / condition_selection | 保留排除行动，与信号伪迹分开 |
| 尚未检查 | 不确认、不标记 | 不作为好样本 |

处理改变后，旧判断保留旧信号依据并变为待复核。重新判断前，不把旧的好/坏决定直接解释为新状态的标签。需要保留处理前后两次判断时，在复核覆盖当前决定之前分别保存会话与贡献包。

首轮可间隔安排少量盲态重复检查，用另一个没有会话记录的数据副本保存第二轮；比较时按同一评分者配对，训练时不把重复检查当成独立样本。重复会话与评分顺序记录在项目本地表中。

本机已准备 output/epochlabel-pilot/review-plan.json：从两份研究样例各均匀随机抽取 30 个 epochs，共 60 个，再安排 6 个盲态重复项，随机种子为 20261030。检查顺序按文件分组，保留文件内的随机顺序，避免每检查一个 epoch 就切换文件。记录同时包含零起始来源索引与一开始的界面编号。该清单没有质量标签、评分者分配或贡献包；匿名项目分组需在正式采集前确定。当前没有按伪迹程度补充抽样，首次评分后再根据实际覆盖决定是否补充。

启动说明位于 output/epochlabel-pilot/START_HERE.md。rater-01 与 rater-02 是两个尚未分配的席位，分别包含 first-pass 和 repeat 的完整数据副本、检查顺序和 launch.ps1。通过各自脚本启动时，LOCALAPPDATA 指向该席位独立的 profile，以隔离评分者 ID；同一席位的两轮沿用同一身份。只复制会话或数据目录不能隔离同一 Windows 用户下默认共用的评分者 ID。各席位的数据副本目前均没有会话标签。

## 导出与核对

评分结束后，用“导出 EpochLabel 贡献包”查看匿名分组和字段，并明确选择是否同意导出波形。项目本地保存即可，暂无公共收集服务。条件字段只保留本轮需要的项目；路径、自由文本和外部原始 TrialID 不进入贡献包。

对少量代表样本核对：贡献波形等于判断状态下的信号（显示滤波另存为观看上下文），epoch 身份与分组一致，只有已人工检查样本进入包，好/坏/不确定及行为排除含义正确。记录总数、每类数量、评分者交叉覆盖、分歧和建议暴露情况。

完成独立评分后再讨论分歧；原始评分保留，共识结果另存。先报告列联表、好坏一致率和不确定比例；若计算 kappa，明确共同评分样本及不确定样本的处理方式，并结合类别比例解释。

## 结束条件和后续模型

试点结束需同时具备：真实独立标签、处理状态匹配、可解释的匿名分组、分歧记录、确认过的贡献样本，以及研究者完整试用反馈。目前这些人工结果尚待采集。

有足够独立被试后才运行已有 eegqc-epochlabel-train。所有同一被试数据、处理前后配对和重复窗口放在同一划分；标准化仅拟合训练集。训练/测试均需包含好坏标签，不确定与行为排除不作为伪迹二分类目标。先报告按被试留出的类别表现与校准，再在数据足够时扩展研究/实验室留出。首轮不承诺发布通用模型。
